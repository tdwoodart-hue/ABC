# ABC frontend work

For UI, layout, styling, or animation tasks, read `.agents/skills/taste-skill/SKILL.md`, `docs/taste-application.md` and `docs/interface-design.md` before editing. Taste Skill is the primary visual review guide. The earlier frontend-design skill remains available as a secondary reference.
Use the existing React, Tailwind, Lucide and Motion stack. Preserve Firebase permissions, persistent journal mounting, per-tab scroll restoration, media behavior, and iOS safe-area / keyboard handling.
Run `npm run lint` and `npm run build`. Review mobile and desktop screenshots and reduced motion. Never use real credentials or write production data for visual testing.
